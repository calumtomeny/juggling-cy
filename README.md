# juggling.cy

The website for Juggling Cyprus: a free weekly juggling meetup at Larnaca Skate Park, every Tuesday from 7pm.

One page in three languages (English at `/`, Greek at `/el/`, Turkish at `/tr/`), built with Vite and no framework.

## Develop

```bash
npm install
npm run dev
```

## Where things live

| To change… | Edit |
| --- | --- |
| Any wording, in any language | `src/i18n/en.json`, `el.json`, `tr.json` |
| Page structure | `src/page.js` (renders each language to HTML) |
| Styles | `src/styles.css` |
| Countdown, throwable balls, scroll effects | `src/app.js` |
| The badge / logo, ball pattern | `src/badge.js` |
| Meeting point, time zone, links, the calendar entry's end time | `src/site.js` |
| The "Find us" map | `npm run map` re-fetches it from OpenStreetMap into `src/map-data.json` |

`index.html`, `el/index.html`, `tr/index.html`, and the favicon, touch icon, share images, "Add to calendar" files (`.ics`) and sitemap in `public/` are generated by the build. Don't edit them by hand.

## Deploy

Pushing to `main` builds the site and publishes it to GitHub Pages (`.github/workflows/deploy.yml`). In the repo's **Settings → Pages**, set the source to **GitHub Actions**.

The site is built for `https://juggling.cy`, the default in `src/site.js`; set under **Settings → Pages → Custom domain**. To move it, change that default (or set `SITE_URL` on the build step) and re-run the workflow so links and share images use the new address.

## Translations

The Greek and Turkish text are drafts awaiting a native speaker's check. Each translated page links to an email for corrections.
