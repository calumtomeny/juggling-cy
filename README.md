# juggling.cy

The website for Juggling Cyprus: a free weekly juggling meetup at Larnaca Skate Park, every Tuesday from 7pm.

One page in three languages (English at `/`, Greek at `/el/`, Turkish at `/tr/`), built with Vite and no framework.

## Develop

```bash
npm install
npm run dev
```

## Where things live

| To change… | Edit |
| --- | --- |
| Any wording, in any language | `src/i18n/en.json`, `el.json`, `tr.json` |
| Page structure | `src/page.js` (renders each language to HTML) |
| Styles | `src/styles.css` |
| Countdown, weather forecast, throwable balls, scroll effects | `src/app.js` |
| The badge / logo, ball pattern | `src/badge.js` |
| Meeting point, time zone, links, the calendar entry's end time | `src/site.js` |
| Other happenings in "Around the island" (they drop off once over) | `src/events.js` |
| The "Find us" map | `npm run map` re-fetches it from OpenStreetMap into `src/map-data.json` |

`index.html`, `el/index.html`, `tr/index.html`, `404.html`, and the favicon, touch icon, share images, "Add to calendar" files (`.ics`) and sitemap in `public/` are generated by the build. Don't edit them by hand.

## Deploy

Pushing to `main` builds the site and publishes it to GitHub Pages (`.github/workflows/deploy.yml`). In the repo's **Settings → Pages**, set the source to **GitHub Actions**.

The site is built for `https://juggling.cy`, the default in `src/site.js`; set under **Settings → Pages → Custom domain**. To move it, change that default (or set `SITE_URL` on the build step) and re-run the workflow so links and share images use the new address.

## Analytics

Cloudflare Web Analytics counts visits. It is cookie-free, and Cloudflare injects its beacon into the HTML at the edge, so it is not in this repo. The page's "no JavaScript" fallback in `src/page.js` ignores scripts from other sites for this reason: ad blockers often block the beacon.

## AI agents (Cloudflare Agent Readiness)

The site is set up to pass the "Content site" checks at [isitagentready.com](https://isitagentready.com):

- `robots.txt` carries Content Signals (`search=yes, ai-input=yes, ai-train=yes`), written by `scripts/assets.mjs`.
- Each page also builds as Markdown (`/index.md`, `/el/index.md`, `/tr/index.md`), plus `/llms.txt` as an index, from `src/markdown.js`.

GitHub Pages can't vary on request headers or add response headers, so two Cloudflare rules on the `juggling.cy` zone do the rest:

| Rule | When | Then |
| --- | --- | --- |
| URL rewrite: "Markdown for agents" | `any(http.request.headers["accept"][*] contains "text/markdown") and http.request.uri.path in {"/" "/el/" "/tr/"}` | Rewrite path to `concat(http.request.uri.path, "index.md")` |
| Response header transform: "Agent discovery headers" | `raw.http.request.uri.path in {"/" "/el/" "/tr/"}` | Set `Link` to `</llms.txt>; rel="describedby"; type="text/plain", </sitemap.xml>; rel="sitemap"`. Add `Vary: Accept` |

On a Pro plan or higher, Cloudflare's own **Agent Readiness → Markdown for Agents** switch can replace the rewrite rule.

The DNS-AID check and the API, OAuth, MCP and commerce checks are for sites that offer agent endpoints or APIs. This site has none, so they are left failing on purpose.
